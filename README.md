# law-doc-query Skill

律师法律资料查询技能 —— 支持**法律法规/司法解释/裁判文书/理解适用**多类型，**本地 + 华宇元典 + ima + 其他法律数据库**多来源，强制溯源防幻觉。

## 这是给谁用的
律师（或法律从业者）的法律资料分散在本地文件夹、华宇元典、ima 知识库等多个来源，类型涵盖规范性文件、裁判文书、理解与适用。希望在 WorkBuddy 任务区里让 agent 基于这些资料回答法律问题，且要求引用可溯源、不得脑补、多源不得混淆、外部源字段与效力状态不误读。

## 支持的文件类型（自动识别）
| 类型 | 标识 | 内容 | 典型查询 |
|------|------|------|---------|
| normative | 规范性文件 | 法律法规、司法解释等（含"第X条"） | 按条号查、关键词搜 |
| case | 裁判文书 | 判决书/裁定书（含案号、"本院认为"） | 按案号查、提取说理与判决 |
| commentary | 理解与适用 | 条文释义、学理解释 | 主题搜索 |
| other | 其他 | 上述之外 | 关键词搜 |

## 支持的数据源
| 来源 | 访问方式 | 配置 | 权威性 |
|------|---------|------|--------|
| 本地文档库 | `law_query.py` 脚本 | 环境变量 `LAW_DOCS_DIR` | 取决于用户收集 |
| 华宇元典 | yuandian-mcp 连接器 | 连接器管理中启用 | 高（专业数据库） |
| ima 知识库 | ima-mcp 连接器 | 连接器管理中启用 | 取决于收藏来源 |
| 其他法律数据库 | 对应 MCP（北大法宝/威科先行等） | 连接器管理中启用 | 高 |

## 配置（一次性）

### 1. 本地文档库（两种方式任选）
- **方式A（推荐，灵活）**：不设环境变量，在包含法律文档库的 WorkBuddy 工作区里直接使用。脚本自动用当前工作目录作为文档库——工作区即文档库。
- **方式B（固定路径）**：设环境变量 `LAW_DOCS_DIR`，适合文档库不在工作区内的情况：
```bash
echo 'export LAW_DOCS_DIR="/path/to/你的法律文档库"' >> ~/.zshrc
```

### 2. 外部数据源（已连接）
- **华宇元典（yuandian-mcp）** ✅ 已连接：法律法规/案例/裁判文书专业检索，条文效力状态可靠
- **ima 知识库（ima-mcp）** ✅ 已连接：个人收藏资料
- **其他**：北大法宝（pkulaw）/威科先行（wk-workbuddy）等，按需在连接器管理启用

连接后 agent 会在跨源查询时自动调用，无需额外配置。

## 使用方式

### 方式一：自然语言（推荐）
在任意任务区直接问，agent 自动识别意图、选择数据源和查询方式：
- "帮我查民法典第143条" → 本地 normative，article；本地无 → 华宇元典
- "有没有不可抗力免责的案例" → 本地 case + 华宇元典案例库
- "（2023）京01民终123号怎么判的" → 本地 case --case-no；本地无 → 元典
- "这条法律理解与适用怎么讲" → 本地 commentary + ima
- "也查查我 ima 里的资料" → 本地 + ima 跨源
- "这条规定现在还有效吗" → 华宇元典确认效力状态

### 方式二：手动调用脚本（本地库）
```bash
SCRIPT=~/.workbuddy/skills/law-doc-query/scripts/law_query.py
python3 $SCRIPT list                                    # 列出所有文档（含类型）
python3 $SCRIPT article 民法典 143                      # 取某法某条
python3 $SCRIPT case --case-no "（2023）京01民终123号"  # 按案号查裁判文书
python3 $SCRIPT case 案例-张三李四                       # 提取某文书结构（本院认为/判决）
python3 $SCRIPT search 不可抗力 --type case --context 3 # 只在裁判文书里搜
python3 $SCRIPT search 民事行为能力 --type normative    # 只在法规里搜
python3 $SCRIPT outline 刑法                            # 看某法大纲
python3 $SCRIPT read 民法典.md --from 17 --to 23        # 读指定行段
python3 $SCRIPT verify 民法典.md --from 18 --to 22 --expect "行为人具有相应的民事行为能力"
```

## 防幻觉机制（核心）
**12道关卡**：6条通用约束 + 6条外部数据源专用约束。

### 通用约束（所有来源）
| 关卡 | 机制 | 作用 |
|------|------|------|
| ① 先查后答 | 禁止凭模型自身知识回答法条/裁判 | 防过时、记错 |
| ② 找不到就说找不到 | 工具未命中不补全 | 防编造 |
| ③ 三类内容区分 | 法条原文/理解适用/裁判原文分列 | 防解释当法条、个案当普遍规则 |
| ④ 引用必经 verify | 本地 verify 逐字比对 + 唯一性校验（unique） | 一字之差能识别；套话重复不误判为已核对 |
| ⑤ 多源不混淆 | 本地/元典/ima/其他分别标注 | 防来源不清 |
| ⑥ 分析标注性质 | agent 分析独立成段 | 防分析冒充原文 |

### 外部数据源专用约束（华宇元典/ima/其他法律数据库 MCP）
| 关卡 | 机制 | 作用 |
|------|------|------|
| ⑦ 字段类型标注 | 标注法条原文/裁判要旨/案件评析/摘要 | 防把要旨、评析当原文引用 |
| ⑧ 案例效力层级标注 | 标注指导性/公报/普通案例 | 防普通案例当普遍规则 |
| ⑨ 条文效力状态确认 | 引用前确认现行/废止/修改 | 防引用已废止条文 |
| ⑩ 原文优先 | 同时有原文和摘要时引原文 | 防摘要当原文 |
| ⑪ 无定位标注 | 摘要无原文定位标"未逐字核对" | 防假装已核对 |
| ⑫ 跨源冲突处理 | 效力以专业库为准、原文以本地为准 | 防擅自合并冲突 |

**律师场景最怕的幻觉**不是"完全编造"，而是：
- "一字之差意思相反"——把"相应的民事行为能力"记成"完全民事行为能力"（关卡④拦截）
- "个案观点当普遍规则"——把普通案例的"本院认为"当成法律（关卡③⑧拦截）
- "已废止条文当现行"——引用已被修订的法条（关卡⑨拦截）
- "要旨当原文"——把法院提炼的裁判要旨当裁判文书原文逐字引用（关卡⑦拦截）

## 测试结果
已在模拟文档库（民法典.md + 刑法.md + 裁判文书.md）上跑通：
- `list` 正确识别三类型（normative/normative/case）并提取案号
- `article` 中文数字（"一百四十三"→143）与阿拉伯数字（"13"→13）均支持
- `article` 条文边界精确：正文内交叉引用（"依据本法第144条规定"）不再被误判为新条文，本条正文完整不被截断
- `case` 成功提取案号、五段结构（原告诉称/被告辩称/经审理查明/本院认为/判决如下）、reasoning、ruling
- `case --case-no` 跨文件按案号检索成功
- `search --type` 按类型过滤正确
- `verify` 识别"相应的"（真）vs"完全的"（假）一字之差；返回 `match_count`/`unique`，重复套话标 `unique=false`
- 路径遍历攻击（`../../../etc/passwd`）已拦截
- 华宇元典/ima 外部源约束已写入 SKILL.md，待真实查询验证字段适配

## 边界与限制
- **只读**：脚本不修改、删除、新建任何文件
- **无网络**（脚本本身）：外部源访问由 agent 通过 MCP 完成，脚本不直接联网
- **无外部依赖**：仅用 Python 标准库
- **文件格式**：本地库仅支持 `.md`；docx/txt 需先转换或扩展脚本
- **条文识别**：依赖"第X条"模式；条文边界仅认行首"第X条"并排除"规定/款/项/之"等引用后缀，正文内交叉引用不会截断条文。若用其他格式需调整 `ARTICLE_START_RE`
- **类型识别**：自动识别可能误判，可在文件开头加 frontmatter `type: normative|case|commentary` 显式标注
- **外部源依赖连接**：MCP 未连接时只查本地；外部源返回内容若无原文定位则标注"[外部摘要，未逐字核对]"
- **外部源字段适配**：约束已通用化，但各 MCP（元典/ima/北大法宝）返回字段名可能不同，首次使用时 agent 需识别字段含义
- **非语义检索**：本地 search 是关键词精确匹配，不是向量检索；库极大时可加 embedding 层
